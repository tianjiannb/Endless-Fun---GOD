# 画作接入指南

面向内容作者：把一个新画作接进画廊，不写代码，三件事——**建场景 → 建数据 → 跑一次生成**。

- 工程根：`E:\游趣无限\Endless-Fun---GOD`
- 引擎：Unity 2022.3.62f3c1（URP）
- 画廊场景：`Assets/Scenes/Gallery/Gallery.unity`
- 画作数据目录：`Assets/Resources/Paintings/`
- 画作场景目录：`Assets/Scenes/Gallery/`

---

## 一、三步接入

### 第 1 步：建画作场景

在 `Assets/Scenes/Gallery/` 下新建场景，命名必须是 `Painting_XXX`（例：`Painting_P3`）。

场景里必须有：

| 物体 | 要求 |
| --- | --- |
| `Main Camera` | Orthographic，Size `5.4`，位置 `(0, 2.2, -10)` |
| `PaintingRoot` | 挂 `PaintingSceneRoot` 组件，`paintingId` 填画作 id |

最小可用场景可以直接复制 `Painting_P1.unity`，只改 `PaintingRoot` 的 `paintingId`。仓库里现有的两个画作场景是自动生成的空场景，可以直接当模板。

### 第 2 步：建画作数据

`Assets/Resources/Paintings/` 右键 → `Create / 游趣无限 / PaintingData`，命名用小写 id（例：`p3.asset`）。

字段：

| 字段 | 作用 | 必填 |
| --- | --- | --- |
| `paintingId` | 唯一 id，与场景 `PaintingRoot.paintingId` 保持一致 | 是 |
| `displayName` | 走进画框时提示里显示的名字 | 是 |
| `sortOrder` | 画廊从左到右的顺序，小的在左 | 是 |
| `sceneName` | 场景名，**不带 .unity**，必须在 Build Settings 里 | 是 |
| `interactable` | `false` 时走不进去，画框显示 `thumbnailLocked` | 否（默认 true） |
| `thumbnail` | 画框正面的图；留空则用 `placeholderSprite` | 否 |
| `thumbnailLocked` | 锁住时显示 | 否 |
| `placeholderSprite` | 白模占位图 | 否 |
| `teaser` | 一句话简介，可留空 | 否 |

### 第 3 步：跑一次生成

菜单 `Tools / 游趣无限 / 0. 一键生成全部（素材 + 场景）`。

这一步会：

1. 重新生成 9 张白模素材到 `Assets/Art/Placeholder/`
2. 按 `sortOrder` 重排画廊，画框 x = `index × 6`
3. 为每个 `PaintingData` 生成/覆盖对应画作场景
4. 把 `Gallery` + 所有画作场景写进 Build Settings
5. 自动打开 `Gallery.unity`

如果只改了画作数据、不想动场景，用 `1. 只重建画廊场景`。

## 二、运行时接口

所有接口都是静态方法，不需要挂脚本、不需要拿引用。

### 进入画作

```csharp
using UnityEngine;

public class MyCustomTrigger : MonoBehaviour
{
    public PaintingData data;

    void OnTriggerEnter2D(Collider2D other)
    {
        PaintingEntry.Enter(data);
    }
}
```

签名：

```csharp
static bool Enter(PaintingData data, bool fade = true);
static bool Enter(PaintingData data, bool fade, out PaintingEntry.FailReason reason);
static bool Enter(string paintingId, string sceneName, bool fade = true);
static bool Enter(string paintingId, string sceneName, bool fade, out PaintingEntry.FailReason reason);
```

返回 `false` 时 `reason` 给出原因：

| FailReason | 含义 |
| --- | --- |
| `NullData` | 传入的 PaintingData 是 null |
| `Locked` | `interactable = false` |
| `EmptySceneName` | `sceneName` 没填 |
| `NotInBuild` | 场景不在 Build Settings 里（跑一次生成即可修） |
| `None` | 成功 |

### 退出画作并带回结果

在画作场景里调用：

```csharp
PaintingSceneRoot root = PaintingSceneRoot.Find();

root.ExitWith("choice_a");                  // choiceId 与 outcome 都用 choice_a
root.ExitWith("choice_a", "ending_good");   // 二者分开
root.ExitAfter(3f, "choice_b", "ending_b"); // 延迟 3 秒再退
PaintingEntry.ExitToGallery();              // 纯返回，不记结果
```

签名：

```csharp
void ExitWith(string choiceId);
void ExitWith(string choiceId, string outcome);
void ExitAfter(float delay, string choiceId);
void ExitAfter(float delay, string choiceId, string outcome);

static void PaintingEntry.Exit(ChoiceResult result, bool fade = true);
static void PaintingEntry.ExitToGallery(bool fade = true);
```

`PaintingSceneRoot` 已自带 Esc 退出（记为 `choiceId = outcome = abandon`），要关掉把 `allowEscapeExit` 取消勾选。


### 读结果

```csharp
GameSession gs = GameSession.Ensure();

IReadOnlyList<ChoiceResult> all = gs.Results;  // 全部结果，按完成顺序
int done = gs.CompletedCount;                  // 已完成画作数
bool p1Done = gs.IsCompleted("p1");            // 某幅画是否走完

ChoiceResult last;
if (gs.TryGetLastResult("p1", out last))
    Debug.Log(last.paintingId + " -> " + last.outcome);

gs.Clear();                                    // 重开一局时清空
```

`ChoiceResult` 结构：

```csharp
public struct ChoiceResult
{
    public string paintingId;  // 哪幅画
    public string choiceId;    // 哪个选择点
    public string outcome;     // 结果标识，如 ending_a
    public bool IsValid;       // paintingId 非空
}
```

结局墙将来只读 `GameSession.Results` 做汇总，画作侧不用关心结局怎么呈现。

### 事件钩子

```csharp
void OnEnable()
{
    PaintingEntry.Entered += OnEntered;
    PaintingEntry.Exited += OnExited;
}

void OnDisable()
{
    PaintingEntry.Entered -= OnEntered;
    PaintingEntry.Exited -= OnExited;
}

void OnEntered(string paintingId) { /* 埋点、BGM… */ }
void OnExited(ChoiceResult r) { /* 刷新画框状态… */ }
```

### 运行时查画作列表

```csharp
foreach (PaintingData d in GalleryRegistry.All) { }  // 已按 sortOrder 排好
PaintingData p1 = GalleryRegistry.Find("p1");
int total = GalleryRegistry.Count;
```

## 三、画廊场景既有约定

| 约定 | 值 | 改哪里 |
| --- | --- | --- |
| 画框横向间距 | 6 | `GallerySceneBootstrap.SlotSpacing` |
| 画框尺寸 | 2.4 × 1.8 | `FrameW` / `FrameH` |
| 画框中心高度 | y = 2.2 | `FrameY` |
| 相机制式 | 正交 5.4，y = 2.2，固定不跟随 | `CameraSize` / `CameraY` |
| 交互半径 | 1.2（只比横向距离） | `PaintingInteract.radius` |
| 玩家身高 | 1.8 | `BuildPlayer` 里的 Collider |
| 可走范围 | x ∈ [-3.2, 画作数×6 + 3.2] | `SidePadding` + 画作数 |
| Sprite PPU | 100 | `PlaceholderArtGenerator` |

画框位置由数据推导：第 i 幅画 x = `i × 6`，结局墙固定在 `画作数 × 6`。加画作后跑一次生成，所有位置自动重排，不用手动摆。

## 四、验证清单

接完一幅新画，按顺序确认：

1. `Assets/Resources/Paintings/` 里有新 `.asset`，`paintingId` / `sceneName` 无拼写错误
2. `Painting_XXX.unity` 在 `Assets/Scenes/Gallery/` 下，且 `PaintingRoot.paintingId` 与数据一致
3. Unity 菜单 `Tools / 游趣无限 / 0. 一键生成全部` 执行后 Console 出现 `[画廊] 全部完成`
4. Build Settings（`File / Build Settings`）里能看到新场景且勾选
5. Play → A/D 走到新画框，走近才出提示，按 E 能进、Esc 能回
6. 回画廊后 `GameSession.Results` 里有该画作一条记录

场景没进 Build Settings 是接入失败最常见的原因，表现是 Console 报 `场景不在 Build Settings 里 → Painting_XXX`，跑一次生成即可。

## 五、常见问题

**Q：走进画框没提示？**
`PaintingInteract` 只认 `PlayerMove2D.Instance`。画廊里没玩家、或玩家身上没挂 `PlayerMove2D`，判定直接返回 false。

**Q：按 E 没反应？**
看 Console 的 `[画廊] 进入画作失败：…` 那行，`NotInBuild` / `EmptySceneName` / `Locked` 三种原因分别对应上面第 2 步的三个字段。

**Q：想加第三幅、第四幅？**
照着第 1、2 步各来一份，`sortOrder` 依次往下排，跑一次生成。画框、相机范围、Build Settings 全部自动扩展。

**Q：想让某幅画暂时锁住？**
`interactable` 取消勾选。玩家走近仍会看到画框，但按 E 会走 `FailReason.Locked` 分支，提示不弹进入文案。

**Q：画作场景里要放自己的美术/逻辑？**
随便加。画廊侧只依赖两件事：场景名能加载、场景里有 `PaintingSceneRoot`（用于 Esc 退出和带回结果）。其余物体跟画廊完全解耦。
