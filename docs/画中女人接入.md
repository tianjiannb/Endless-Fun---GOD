## 二、生命周期

```
Gallery（常驻 GameSession）
  └ 走到 Frame_chie 按 E
      → PaintingEntry.Enter(chie, Scene_Chie, fade)
      → Scene_Chie 加载，ChieBootstrap.Start() → EnsureBuilt()
      → 三波修复 / 对话 / Hold / 揭画 / 结局
      → 抽离过场（ChieExtractView，3.2s）
      → ChieFlow 黑场
      → GalleryBridge.Exit(chie, choiceId, outcome)
      → ChieGalleryLink → PaintingEntry.Exit(ChoiceResult, fade:false)
      → GameSession.Exit → LoadScene(Gallery)
```

- 单独打开画2 工程时 `ChieGalleryLink` 不存在，`GalleryBridge` 没有实现，只打印
  `[Chie] 未找到 Scene_Gallery，留在本场景。请检查 Build Settings。` 并停在黑场，不崩。
- 相机改为装配期注入（`ChieBootstrap.EnsureBuilt()` 内），画2 不再抢 `Camera.main`，也不会改画廊相机参数。
- `ChieBootstrap` 幂等：`EnsureBuilt()` 可被画廊/模块反复调用，重复调用直接返回同一个 `ChieFlow`。
- `_moduleDriven` 默认 `false`（旧场景 YAML 缺字段即自启），勾上表示由外部调用 `EnsureBuilt()`。
- QA 驱动器（`-chieqa`）只在场景里存在 `ChieBootstrap` 时接管，画廊场景不会被它劫持。

## 三、装配契约

- 公开面：`ChieBootstrap.Config`、`ChieBootstrap.Cam`、`ChieBootstrap.EnsureBuilt() → ChieFlow`。
- `ChieFlow.Bind(config, view, painter, pointer, judge, wave, runner, dialogueView, toolbar, ending, reveal, markers, fade)` 由装配器调用；`AttachExtract`、`AttachSfx` 在其后挂接过场与音频。
- 运行时依赖：`com.unity.textmeshpro` 3.0.7、`com.unity.ugui` 1.0.0、URP 14.0.12。
  中文 SDF 字体 `Resources/Chie/Fonts/ChieSDF` 自带 1245 字预烘焙图集。
- 美术资源为 1920×1080 的 base/fixed/mask 三层，mask 用 `r + 2g + 4b` 编码破绽 ID，均开 Read/Write、无压缩、Point 过滤。

## 四、交互与手感契约

| 项 | 实现 |
| --- | --- |
| 工具栏 | World Space 左侧竖列，`ColumnX=40`、`ColumnY=700`，格 96px、间距 24px |
| 命中 | 每个按钮/选项行都有一张全尺寸透明 `Image` 作 Hitbox，图标与 TMP 均关射线，避免字形命中塌陷 |
| 选项行 | `ChoiceGroup` 高 220，行尺寸 1500×64，行距 68 |
| 笔刷 | 半径 30px，沿轨迹按 `BrushStepPx=4` 分段盖印，抬起不再补画末段 |
| 判定 | 每姿势独立覆盖位图，`Coverage` 取所有姿势最大值，达 `CoverThreshold` 即修复 |
| 上色门 | 嘴、影子仍需吸管取对色；窗外与灰尘用橡皮，其余用画笔 |
| 三波 | 修好 1 处进第二波（窗/灰开放），修好 2 处进第三波（吸管解锁） |

## 六、已知限制

- 占位美术仍是程序生成的色块，不是成品美术。
- `base_sit.png` 的导入类型被改成 Sprite（仅为画廊缩略图），主对象仍是 `Texture2D`，Read/Write 保持开启，画笔/吸管逻辑不受影响。
- 结局 Shatter 特效以「抽离」过场替代（裂开→剥离→上浮→溶解），未使用原 `turn.mp4` 视频通道。
- 画2 的三波修复玩法仍是 §5.5.4「点击画中物件」的加厚版，剧情选择点尚未压缩成「2 个结构性选择点」。
